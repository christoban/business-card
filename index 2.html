🚀 Présentation Complète du Projet Final

CodeMentor Studio

IDE pédagogique multilangage, interactif et intelligent, conçu pour accompagner les étudiants africains dans l’apprentissage de la programmation et la réalisation de projets, entièrement offline et optimisé pour des machines peu puissantes.

Problématique

  • Peu d’accompagnement personnalisé pour les étudiants.
  • Les IDE classiques sont lourds, peu pédagogiques et souvent dépendants d’Internet.
  • Absence de solution locale adaptée aux besoins éducatifs en Afrique.

Solution proposée

CodeMentor Studio est un IDE desktop 100% offline qui explique les concepts, propose des exercices interactifs, guide le debugging, accompagne les projets pas à pas et suit la progression des apprenants.

Fonctionnalités du produit final

1️⃣ Éditeur avancé

  • Coloration syntaxique (Python, Java, C, JS)
  • Numérotation des lignes
  • Sauvegarde automatique + restauration
  • Console intégrée

2️⃣ Exécution double

  • Mode Manuel (par défaut)
  • Mode Live activable
  • Sandbox sécurisé + timeout

3️⃣ Explication de code

  • Analyse AST / logique
  • Explication ligne par ligne
  • Détection d’erreurs fréquentes + analogies

4️⃣ Exercices interactifs

  • Exercices par niveau
  • Tests automatiques + feedback détaillé
  • Suivi de progression

5️⃣ Mode Debugging

  • Code volontairement erroné
  • Correction guidée par feedback
  • Entraînement à la résolution de problèmes

6️⃣ Accompagnement projet

  • Guidage étape par étape
  • Questions stratégiques sans donner le code
  • Conseils sur structure, stockage et interface

Architecture technique

UI Layer
 ├── EditorWidget
 ├── ConsoleWidget
 ├── ModeToggle (Live/Manuel)
 └── ExercisePanel

Core Layer
 ├── ExecutionEngine (sandbox, live/manual)
 ├── CodeExplainer (AST, analogies)
 ├── ExerciseEngine (tests automatiques)
 ├── DebugEngine (erreurs simulées)
 └── ProjectCoach (guide projet interactif)

Data Layer
 └── SQLite (exercices, progression, paramètres)

Outils recommandés (MVP & produit final)

UI & Éditeur: PyQt6, QScintilla, QPlainTextEdit, Pygments.

Explication: ast, inspect, difflib, re, textwrap, markdown/rich, OpenAI API (optionnel pour analogies avancées).

Exercices & progression: unittest/pytest, sqlite3, SQLAlchemy (optionnel), random.

Debugging & exécution: subprocess, exec/eval contrôlé, traceback, threading/QTimer, multiprocessing, timeout.

Données: SQLite (léger et offline), pandas (optionnel pour statistiques).

Valeur pédagogique

  • Transforme les cours passifs en apprentissage actif.
  • Encourage la réflexion plutôt que la copie.
  • Développe les compétences pratiques et théoriques.
  • S’adapte au contexte local: offline, multilingue, faible machine.
